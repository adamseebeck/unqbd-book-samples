# Chapter 11 Executable Checkpoint

Copy this complete directory to a working folder, keep its global.json active, and run `dotnet run --project LibraryDesk/LibraryDesk.csproj --no-launch-profile -- --environment Development --urls http://127.0.0.1:58631`. Use one fixture at a time or select a different port. The generated App shell and client assembly are included; focused files are listed in the chapter. All keys are ephemeral in this local fixture; real deployment key management is a separate check.

Stop the Development host before the separate Production check: `dotnet run --project LibraryDesk/LibraryDesk.csproj --no-launch-profile -- --environment Production --urls http://127.0.0.1:58631`. This focused checkpoint has no Production feedback page. Check GET404 for each lab path and the absence of local sign-in controls; these are GET/UI observations alongside the source environment guard. Chapter23 uses the finished app and its /static-feedback form for the separate valid-token POST exclusion proof.
