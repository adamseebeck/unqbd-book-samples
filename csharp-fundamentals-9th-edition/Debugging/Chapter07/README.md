# MethodDebug

Break on AddBonus(10), Step Into the call, inspect score and adjusted, look at the caller in Call Stack, and Step Out. The result is 15.

In Visual Studio open MethodDebug.csproj, choose Debug configuration, and use F9, F5, F10, F11, Shift+F11, and Shift+F5 as the chapter explains. In VS Code open this folder with C# Dev Kit, use Run and Debug, and inspect VARIABLES, WATCH, and CALL STACK. Stop before editing, save, and start a fresh run. These experiments are separate from StudentTracker.
