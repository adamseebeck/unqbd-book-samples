# ObjectDebug

Break on second.Age = 31; expand both variables. They refer to one object, so both display age 31 after stepping. Replace second = first with a new Person initialized from first to compare separate objects.

In Visual Studio open ObjectDebug.csproj, choose Debug configuration, and use F9, F5, F10, F11, Shift+F11, and Shift+F5 as the chapter explains. In VS Code open this folder with C# Dev Kit, use Run and Debug, and inspect VARIABLES, WATCH, and CALL STACK. Stop before editing, save, and start a fresh run. These experiments are separate from StudentTracker.
