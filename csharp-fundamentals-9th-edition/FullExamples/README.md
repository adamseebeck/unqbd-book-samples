# Complete lesson examples

In Visual Studio 2026 open Chapter03/Chapter03.csproj with File > Open > Project/Solution. Build the solution; use Test > Test Explorer for tests and Ctrl+F5 for console applications. Use F5 to attach the debugger and the chapter's breakpoint/stepping instructions. The terminal instructions below are the VS Code alternative.

Chapters 3-26 have one independent group each. Chapter 19 contains the production library and xUnit test project. Chapter 22's console project is SchoolDemo.csproj. Other complete console lessons use ChapterNN.csproj. Run from the book folder as described in ../README.md, supplying the inputs shown in the chapter. Setup exercises for Chapters 1-2 are in the book.
