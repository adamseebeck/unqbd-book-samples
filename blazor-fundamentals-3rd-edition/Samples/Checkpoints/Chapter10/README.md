# Chapter 10 Executable Checkpoint

Copy this complete directory to a working folder, keep its global.json active, and run `dotnet run --project LibraryDesk/LibraryDesk.csproj --no-launch-profile -- --environment Development --urls http://127.0.0.1:58631`. Use one fixture at a time or select a different port. The generated App shell and client assembly are included; focused files are listed in the chapter. All keys are ephemeral in this local fixture; real deployment key management is a separate check.
