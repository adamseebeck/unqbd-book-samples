# Activity answers

Chapter01 is a text activity. Chapters 2 to 23 start from the prepared unsolved folders under Samples/ActivityStarts. Copy the selected folder and open its LibraryDesk/LibraryDesk.slnx in Visual Studio. Each answer explains the change and expected behavior. Match its chapter number; a cumulative checkpoint is the main project at the end of a chapter, not an exercise solution.

Use Test Explorer to run the named exercise project or selected test. Chapter 16 has three cases, Chapter 18 uses the existing 18-test suite, and the other supplied exercise suites have one test each. Chapter 2 starts with a deliberately unavailable SDK pin. Chapter 16 starts with a missing component parameter, and Chapter 18 with duplicate favorites. Those are the intended investigations, not download mistakes.
