# Chapter 21 Activity Code Delta

From Samples/ActivityInvestigations run `python create_copy.py --chapter 21 --output C:/BookExercises/Chapter21` with Python 3, choosing a new working folder outside the companion code. The script checks that its starting files are unchanged, copies the complete project and applies delta.json to the copy.

From that new directory run `dotnet run --project LibraryDesk/LibraryDesk.csproj --no-launch-profile -- --environment Development --urls http://127.0.0.1:58631` with the SDK that global.json selects.

The message textarea references the new existing help paragraph through aria-describedby, while its original label still targets the textarea. Invalid and valid form cases behave as before. Check keyboard and focus behavior in a browser, and screen-reader behavior if you have one.

To start over, make another fresh copy. Make deliberate failures only in the disposable copy, and run the check to confirm the outcome above.

The disposable copy also contains a focused test: `dotnet test Tests/Chapter21.Tests.csproj`. A component test doesn't cover a browser module download or CSS layout; check those in a browser.
