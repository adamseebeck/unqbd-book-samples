# Activity solutions

In Visual Studio 2026 open Chapter03/Chapter03Activity.csproj with File > Open > Project/Solution. Build the solution; use Test > Test Explorer for tests and Ctrl+F5 for console applications. Use F5 to attach the debugger and the chapter's breakpoint/stepping instructions. The terminal instructions below are the VS Code alternative.

Try each activity before opening its solution. Flat ChapterNN.cs files correspond to the book's single-file solution paths; matching ChapterNN folders provide runnable projects. Chapter 19 contains a library and tests, and Chapter 22 contains a CRUD console program plus a separately managed migration experiment. Their local README files explain those commands. Chapters 1-2 are setup activities documented in the book.
