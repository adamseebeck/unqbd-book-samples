# unQbd Technical Series: companion code

Example code and activity solutions for the unQbd technical books by Adam Seebeck. Each book has its own folder with a README explaining how to run its examples.

| Book | Subtitle |
| --- | --- |
| [C# Fundamentals, Ninth Edition](csharp-fundamentals-9th-edition/) | A Beginner’s Guide to C# 15 and .NET 11 with Practical Examples and Exercises |
| [ASP.NET Core Fundamentals, Second Edition](aspnet-core-fundamentals-2nd-edition/) | Building Modern Web Applications with .NET 11 |
| [Entity Framework Core Fundamentals, Second Edition](efcore-fundamentals-2nd-edition/) | Building Data-Driven Applications with .NET 11 |

You can read and copy any file in your browser. To run the examples, clone this repository or download it as a ZIP with the green **Code** button, then follow the book folder's README.

The books are available at [unqbd.com](https://www.unqbd.com) and from major retailers. Found a problem in the code? Contact us at [unqbd.com/Contact](https://www.unqbd.com/Contact).
