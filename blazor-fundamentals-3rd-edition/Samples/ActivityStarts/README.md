# Prepared activity starts

These are unsolved starting projects for Chapters 2 through 23. Copy the complete
ChapterNN folder to a new location outside the companion download, then open
LibraryDesk/LibraryDesk.slnx in Visual Studio. Stop the previous app before
starting a copy on the same port. Read the chapter and that copy's README for the
investigation or change to make. A supplied Tests project is included in the
solution; its tests may fail until you complete the exercise.

Chapter 2 intentionally requests an unavailable SDK. Repair the outer global.json
as the exercise describes, then reload the solution. Chapter 4 starts from its
unchanged checkpoint. Chapter 1 is a text exercise and has no project.

ActivityInvestigations/create_copy.py remains an optional way to reproduce these
starts with Python. ActivitySolutions contains separately labeled worked answers.
